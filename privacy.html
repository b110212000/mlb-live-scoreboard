隱私政策

更新日期：2026 年 10 月 10 日

網站與影片功能

本網站為獨立 MLB 比分與影片推薦網站。影片功能使用 YouTube API Services 取得官方頻道的公開影片標題、介紹、頻道資料及縮圖網址，依比賽資訊篩選，提供連結至 YouTube；不下載、轉存、剪輯或重新上傳影片，也不要求 YouTube 登入或 OAuth 授權。

資料與用途

  • 比賽與球員資料由瀏覽器連線至 MLB Stats API，球隊與球員圖片連線至 MLB 圖片服務；這些服務可取得網路連線所需的資訊。
  • YouTube 公開影片資料由 Cloudflare Worker 呼叫官方 API 取得。Worker 只傳送頻道、球隊、日期與影片 ID 等查詢條件，不傳送訪客的推播 endpoint、裝置識別碼或 YouTube 帳號資料。
  • 同意影片功能後，縮圖由瀏覽器直接向 YouTube 圖片服務載入；Google 可取得 IP 位址、瀏覽器及請求資訊。點擊影片、頻道或搜尋連結後，依 YouTube／Google 自身政策處理，包括可能使用的 Cookie。本網站不嵌入播放器或 YouTube 廣告。
  • 公開影片推薦結果在 Worker 邊緣快取最多 6 小時，頻道識別資訊最多 24 小時；瀏覽器只暫存在記憶體，最多 15 分鐘。快取逾期須重新查詢，不永久建立影片資料庫。
  • 影片功能的同意版本以 sessionStorage 記錄於本機分頁，關閉分頁或按「撤回影片功能同意」後移除。撤回後清除本機影片記憶體快取，停止載入影片列表與縮圖；不影響 Google 已取得的資料。
  • 本網站以 localStorage 保存比賽通知裝置識別碼、已訂閱場次、VAPID 公開金鑰與顯示設定。Web Push 另由瀏覽器保存訂閱；通知功能需使用者允許通知。Cloudflare Durable Object 保存裝置識別碼、比賽與推播 endpoint／加密金鑰，用來發送所訂閱比賽的通知。取消場次訂閱、終場通知完成或 endpoint 過期時移除該場訂閱。
  • GitHub Pages、Cloudflare 與各資料服務可能依其政策保留技術與請求紀錄。本網站未加入廣告、分析追蹤或 AI 翻譯服務，不出售使用者資料。

選擇與刪除

不接受影片功能政策仍可使用比分功能。可在影片區撤回同意。要刪除比賽通知資料，先以鈴鐺取消各場訂閱，再關閉瀏覽器通知權限或刪除網站儲存資料；只清除本機儲存不會自動取消伺服器既有訂閱。

政策或刪除問題可透過專案問題回報聯絡維護者；請勿在公開回報貼上推播 endpoint、金鑰或其他個人資料。
